# Superseded: PolyMind council interpretation

Status: superseded as the definition of PolyMind, 2026-10-09.

**Start with [PolyMind: unified multi-model application](POLYMIND_PLATFORM_DESIGN.md).** PolyMind is one app where a user opens one chat and all participating models coordinate their strengths, tools and agents using shared task context and capability awareness. It is not defined by debate, voting or code review.

The earlier PM-COUNCIL-001 document narrowed the product incorrectly to a planning/review council. Its [historical text remains in Git history](https://github.com/arx-fortis/clawcare-agent/blob/4c887731a356af19006012be2d08cb6cba3f5596/POLYMIND_COUNCIL_WORKFLOW.md); that historical interpretation is not the current product specification.

Useful technical safeguards are incorporated into the corrected design: broad model participation, scoped permissions, evidence and dissent, bounded execution/spending, durable state, one coordinator, single-resource writers and immutable-commit coding reviews. A coding council can be an optional subsystem, not the platform's identity.

ClawCare remains independent. This correction is documentation only; no model/API integrations, accounts, agents, tool connections, installation, deployment or merge have been performed.
